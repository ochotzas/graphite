# Voice & UI copy

Write like Apple: short, plain, human, calm. The UI is quiet, so the words are quiet too.

## Rules
- **Sentence case everywhere.** "Create project", not "Create Project". Never ALL CAPS.
- **Short.** Buttons 1–3 words. Titles ≤ 5 words. Descriptions one sentence.
- **Verbs on buttons**, naming the actual outcome: "Save changes", "Send invite", "Delete photo". Never "OK", "Submit", "Yes", "Click here".
- **Talk to the user as "you"**. Use "we" sparingly. Never blame the user.
- **No exclamation marks** except a genuine celebration (once). No emoji in UI chrome.
- **No filler**: "Simply", "Just", "Easily", "Seamlessly", "Unlock", "Supercharge", "Elevate", "Leverage", "Effortless", "Next-level", "Revolutionary", "Powered by AI".
- Numbers as digits ("3 items"). Use the real ellipsis "…" for actions that open more input ("Rename…").
- Use curly quotes and apostrophes in display text: ’ “ ”.
- **No trailing periods** on titles, labels, buttons and captions. Only multi-sentence text keeps them.
- **Titles name the context**, never greet: "October 2026", not "Welcome back, Sam! 👋".
- **Changes say what they compare to**: "+12% vs last month", not "+12%!!".
- **Short placeholders**: "Search", not "Search anything...".
- **No unverifiable claims** ("10x faster", "Loved by 10,000+ teams"). Ask if they're real; keep them quiet and specific, or remove them.
- **Mock data looks real**: plausible numbers and names, never `$123,456` or `[X]`.

## Patterns

| Situation | ❌ | ✅ |
|---|---|---|
| Empty state | "No data found." | "No projects yet" + "Create one to get started." |
| Error | "Error 500: Request failed" | "Couldn’t save your changes. Check your connection and try again." |
| Confirm delete | "Are you sure?" [Yes] [No] | "Delete “Q3 plan”?" "This can’t be undone." [Delete] [Cancel] |
| Success toast | "Success! Your item has been saved successfully!" | "Saved" |
| Hero headline | "Unlock the power of seamless collaboration" | "Plan together. Ship faster." |
| Field helper | "Please enter a valid email address" | "Use the email you sign in with." |
| Loading | "Loading, please wait..." | "Loading…" (or nothing; use skeletons) |
